# Журнал уведомлений (Android)

Приложение записывает все входящие пуш-уведомления в базу на телефоне.
Поиск, просмотр полного текста, копирование, экспорт в CSV (Excel), очистка.

## Как получить APK

### Вариант 1 — GitHub (без установки чего-либо)
1. Создайте новый репозиторий на github.com.
2. Загрузите туда ВСЁ содержимое этой папки (вместе со скрытой папкой `.github`).
   Проще всего: GitHub Desktop или `git push`.
3. Вкладка **Actions** → сборка запустится сама (~3–5 мин).
4. Откройте завершённую сборку → внизу **Artifacts → NotifLog-apk** → скачайте zip, внутри `app-debug.apk`.

### Вариант 2 — Android Studio
File → Open → эта папка → Build → Build APK(s).

## Первый запуск
1. Установите APK (разрешите установку из неизвестных источников).
2. Нажмите «Дать доступ к уведомлениям» → включите «Журнал уведомлений».
3. Готово — новые уведомления пишутся автоматически, даже когда приложение закрыто.

## Важно
- Старые уведомления (до установки) прочитать нельзя — Android их никому не отдаёт.
  При включении сохраняются только те, что сейчас висят в шторке.
- Xiaomi / Huawei / Realme / Samsung: в настройках приложения поставьте
  «Батарея → Без ограничений» и включите «Автозапуск», иначе система может
  отключить запись.
- Постоянные уведомления (музыка, загрузки, VPN) и повторы одного и того же
  уведомления в течение 10 минут не записываются.
- Данные хранятся только на телефоне, в интернет ничего не отправляется.

## Файлы
- `NotifListener.kt` — служба, которая ловит уведомления
- `LogDb.kt` — база SQLite (журнал)
- `MainActivity.kt` — экран со списком, поиском и экспортом
